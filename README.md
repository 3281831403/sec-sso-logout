用户点了退出登录，可另外两个系统的会话还在，直到它们各自的票据自然过期：登出必须传播到该会话的全部下游参与者，不能只送达到其中的第一个；每一次传播的结果都要逐个确认并留下记录，失败项要能单独重试，重试必须幂等，已经成功的下游不得再被重复通知；登出令牌必须同时绑定主体与签发方，签发方不在受信列表内时令牌不得生效，受信判定必须完整匹配；登出被接受之后，本地会话必须立即失效，而不是等它自然过期；批量登出时各会话独立处理，每个会话各自取自己的下游，互不共用结果。不变量：对同一会话重复登出，结果保持一致；登出完成后，该会话的任何下游都不再被判定为有效。

## 数据约定

登出令牌是竖线分隔的五段字符串，依次为类型、版本、主体、签发方与会话标识；版本当前为 v1。

下游参与者是字典，至少包含参与者名、登出地址与主体。会话是字典，至少包含会话标识与主体。注册表以会话标识为键，值是该会话的下游参与者列表，同一个参与者只应出现一次。

会话存储是字典，以会话标识为键，条目至少包含主体、有效标志、过期时间与失效时间。条目有效当且仅当有效标志为真且过期时间晚于当前时间。

传播结果是字典，records 是逐条通知记录列表，每条记录包含参与者名、地址、主体、成功标志、尝试次数与失败原因；complete 表示是否全部通知成功。

## 接口约定

parse_logout 返回主体、签发方、会话与版本，令牌不合法时抛出 ValueError。

check_token 返回布尔值，签发方必须与受信列表中的某一项完全相同。

targets_of 返回该会话的下游参与者列表，同一参与者只保留一次。

propagate 逐个通知并返回传播结果，任何一次通知抛错都只算该参与者失败，不影响其他参与者。

retry_failed 返回新的传播结果，只重试失败项；没有失败项时不得再次通知。

invalidate_local 返回失效报告，包含会话、主体、是否改变、有效标志、失效时间与过期时间。

validate_result 返回问题列表，健康结果返回空列表。

logout_batch 为每个会话返回各自的传播结果、完成标志与失效报告，会话之间互不影响。
